In /home/matt/Git/Whackford/jpeg-decoder/jpeg/frame.wack add `frame.check ( frame -- )`, contract first (declare + the tests below, then the body). It must run before any geometry word (those divide by hmax, which must already be known non-zero). Each refusal is `CODE "message" refusal trap` (or refusal-n with the offending value) inside a `when`. Checks, in this order so each test trips exactly one:
1. ncomp (and comps length) between 1 and MAX_COMPONENTS, else BAD_COMPONENT.
2. precision 8 or 12, else BAD_PRECISION.
3. width and height each between 1 and MAX_DIM, else LIMIT_DIM. Decision: a zero dimension is refused as LIMIT_DIM (libjpeg rejects height 0 too, JERR_EMPTY_IMAGE; DNL support is a later decision); record this in the header comment.
4. width*height computed in i64 at most MAX_PIXELS, else LIMIT_PIXELS.
5. each component h and v between 1 and 4, else BAD_COMPONENT.
6. hmax a multiple of every h and vmax of every v (libjpeg's rule), else BAD_COMPONENT.
7. no two components share an id, else BAD_COMPONENT.
8. each tq between 0 and 3, else BAD_TABLE.
