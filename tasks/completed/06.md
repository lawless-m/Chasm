- `struct encoder` with: `o: out`, `bw: bitwriter`, `w: i32`, `h: i32`, `wb: i32` (blocks across, (w + 7) / 8), `pw: i32` (the padded width wb x 8), `buf: bytes` (one MCU row: 8 sample rows of pw bytes, row r at r x pw), `blk: array i32` (the 64-entry DCT workspace), `qt: array i32` (the scaled luminance table, natural order), `nat: array i32` (qtables.natural), `dct: htab`, `act: htab`, `pred: i32` (the previous block's quantised DC, 0 at the start), `rows: i32` (sample rows held in buf, 0..8), `y: i32` (image rows received so far).
- `encoder.on ( out i32 i32 i32 -- encoder )`: the open output, width, height, quality: allocates everything above once, writes the headers through the writer words exactly as E0's encode.wack main does (`writer.soi`, `writer.app0`, `0 qt writer.dqt`, `w h writer.sof0`, `0x00 htables.dc-lum-bits htables.dc-lum-vals writer.dht`, `0x10 htables.ac-lum-bits htables.ac-lum-vals writer.dht`, `writer.sos`), makes the bit writer `o 0 0 bitwriter.new`, and returns the struct.
- `encoder.open ( str i32 i32 i32 i32 i32 str -- encoder )`: path, width, height, ncomp, quality, sample, icc (ARCHITECTURE.md's data-flow signature): ncomp other than 1 is a plain trap `"E1: greyscale only"` (checked before the output is opened; E2 adds colour); sample is accepted and ignored (greyscale ignores it); icc other than `""` is a plain trap `"E1: no ICC"` (E4); then `out.open` and encoder.on.
- `encoder.block ( encoder i32 -- )`: codes block column bx of the buffered MCU row: for r in 0..7 and c in 0..7, blk[r x 8 + c] = buf[r x pw + bx x 8 + c] - 128 (convsamp); `blk fdct.block`; `blk qt quantise.block`; `bw dct act nat blk pred huffenc.block`; then pred = blk[0].
- `encoder.mcu-row ( encoder -- )`: encoder.block for bx from 0 to wb - 1, then rows = 0.
- `encoder.finish ( encoder -- )`: `bw bitwriter.flush` then `o writer.eoi`; it does not close the output (the test seam: tests run on a `fx.out` with no file). The next task adds the bottom-edge replication and the row-count check here.
