Structs (reference.md 10a; struct fields are mutable, a struct value is a GC reference): `struct component  id: i32  h: i32  v: i32  tq: i32` and `struct frame  kind: i32  precision: i32  height: i32  width: i32  ncomp: i32  comps: array component` (kind is the SOF marker byte: 0xC0 0xC1 0xC2 0xC9 0xCA). Note: `n array.new ( array component )` must be bound to a local with nothing else on the stack (whole-stack assertion).

Geometry words (T.81 B.2.2 and JPEG-NOTES.md), all pure, contract first with declare + tests:
- `ceil-div ( i32 i32 -- i32 )` for positive operands.
- `frame.hmax ( frame -- i32 )`, `frame.vmax ( frame -- i32 )`: the maximum sampling factors over components.
- `frame.mcus-wide ( frame -- i32 )` = ceil(width / (8*hmax)); `frame.mcus-high` likewise with height and vmax.
- `frame.comp-blocks-wide ( frame i32 -- i32 )` for component index i: ceil(ceil(width*h / hmax) / 8), the non-interleaved grid, not padded to MCUs; `frame.comp-blocks-high` likewise.
- `frame.blocks-padded ( frame -- i64 )`: the sum over components of (mcus-wide*h) * (mcus-high*v), i.e. blocks padded to whole MCUs (the coefficient-store size driver). Compute in i64 (`i64` widens an i32).

Expected values to test: for `17 17 fx.ycc420`: hmax 2, vmax 2, mcus-wide 2, mcus-high 2, component 0 blocks-wide 3, component 1 blocks-wide 2, blocks-padded `24 i64`; for fx.grey: mcus-wide 1, blocks-padded `1 i64`.
