No frame: refuse NO_FRAME.
- `colour.row ( colour i32 bytes i32 i32 bytes i32 -- )`: the tables, the space (0, 1 or 2), the upsampled buffer `ups`, the number of rows per component block `rows`, the row r, the output row `out`, and the width. The upsampled buffer holds ncomp blocks of rows*width samples: component c's sample at row r, column x is ups[c*rows*width + r*width + x]. Space 0: out[x] = ups[r*width + x]. Space 1: for each x, colour.ycc of the three components' samples into out[3x], out[3x+1], out[3x+2]. Space 2: out[3x + c] = component c's sample.
