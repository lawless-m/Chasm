It: sets buf 0, nbits 0, exhausted 0, marker 0 (the unread bits of the interval are padding, discarded as libjpeg's process_restart does; the exhausted flag is reset because the next interval starts fresh); then looks for a marker at pos: if pos >= data length, or the byte at pos is not FF, return -1 with pos unchanged; otherwise advance q over the run of FF bytes from pos; if q >= data length, or the byte at q is 00 (a stuffed byte, not a marker), return -1 with pos unchanged; otherwise set pos to q + 1 (just past the marker) and return the marker byte. It never refuses: whether the byte is the expected RSTn (D0 to D7 in sequence) or something else (EOI, garbage) is the scan layer's decision (BAD_RESTART in M2); say so in a comment. Note that when bits.fill has already recorded a marker, pos is at the first FF of that marker, so the same scan finds it; no special case.
