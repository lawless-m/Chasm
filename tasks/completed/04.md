Context: upsample.plain ( plane bytes i32 i32 i32 -- ) (plane, dst, dst offset, output width, output rows) replicates a plane's samples: per output row r it computes `from` = base + (r / vexp) * stride and `to` = off + r * width, then for hexp = 1 copies `width` bytes one at a time (`dst to x0 i32.add  src from x0 i32.add bytes.at  bytes.at!`, a bounds-checked load and store per byte) and for hexp > 1 does `src from x1 hx i32.div_u i32.add bytes.at` per output sample, a division each. rows.emit uses it for every component whose method is 0: in fancy mode that is every full-size plane (big12's Y plane, 12 million bytes per decode, YCCK's Y and K, CMYK's M, Y and K), in nosmooth mode every plane (24 million chroma samples through the division on big12). The plane's row is at least `width` bytes long (stride is the MCU-padded width), so `src from width bytes.slice` is in range. upsample.plain12 (array i32) is NOT part of this task.
