In rewind mode nothing with a side effect may run before the resume site: no `local.set` (it would clobber a restored local), no memory store, no call, no trap. Implement for transformed functions (`self.ctx.transforms(&self.name)`): (1) a pure pre-scan `has_site(&Node) -> bool` over the AST: `Name(n)` is a site when n is `call`, or `ring.submit` (conservative), or n is not a local/capture/assignment (`n!`), not a shuffle, numeric, special or inline primitive (`prims::shuffle`, `prims::numeric`, `prims::special`, `eq`/`hash`, `array.*`) and (under `Unwind::All`) names any word, or (under `Only(s)`) `s` contains n or the name of any instance of n (store template names in `s` too when the set is built, next task); `Alt` is always a site; `If`/`When`/`Unless`/`While`/`Until`/`Times`/`Each`/`Map`/`Filter`/`Fold`/`Match` are sites when any sub-body has one; `Quote`, `Lit`, `Bind`, `Assert`, `Tick`, `Leave` are not (a quotation value's body is a separate function). A superset is safe: wrongly calling something a site only costs code. (2) A helper `skip_in_rewind(before: &[Ty], after: &[Ty], flow, emit: impl FnOnce(&mut Self))` that emits `i32.const 0; i32.load UNWIND_MODE; i32.const REWINDING; i32.ne; if (block type before → after)` then `emit`, `else` drop every value of `before` and push a dummy of every value of `after`, `end`; when `flow` is Diverged the block is typed before → before, the else branch is `unreachable`, and an `unreachable` follows the `end` (so the enclosing construct's expected results still validate). The helper calls `open_label`/`close_label` so `leave` branches inside stay correct; the decision to wrap must therefore be made BEFORE emitting the code (the pre-scan), never by wrapping already-emitted code. (3) `seq`: group maximal runs of consecutive nodes with `!has_site` and emit each run inside one `skip_in_rewind` (params = lowered checker stack before the run, results = after); nodes with sites are emitted unwrapped (their inner constructs handle themselves, next tasks). (4) `run`: wrap `line_prologue` in `skip_in_rewind` (empty before, the inputs after); the param pushes and the closure env cast stay unwrapped (dummies are harmless; the entry restore sets `env_view` afterwards).
