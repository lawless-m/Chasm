Read tmp/unwind-design.md step 4 and in crates/core/src/check.rs the `node` arms `If`, `When`/`Unless`, `While`, `Until`, `Times`, and `each`, `map`, `filter`, `fold`, `coll_loop_open`, `array_prologue`, `source_array`, plus `has_site`, `skip_in_rewind` and `sites` from the previous tasks. Sites are numbered in emission order, so the sites inside any construct form a contiguous range `[lo, hi)` (`lo = self.sites.len()` before walking it, `hi` after). For a transformed function, in a construct that `has_site`: (1) `If`: the then-branch's range is `[lo, mid)` and the else-branch's `[mid, hi)`; before `I::If(bt)` replace the condition with `cond; (resume < mid); (mode == REWINDING); select` so rewinding takes the branch holding the site (when rewinding into the construct, `resume` is always inside its range). The branches are walked into buffers before the `if` is emitted, so `mid` is known; emit the `select` sequence just before `I::If`. (2) `When`: `cond; i32.const 1; mode==REWINDING; select`; `Unless`: the same with `i32.const 0` BEFORE the existing `i32.eqz`. (3) `While`: the condition sequence is walked by `seq` (its site-free runs are skipped, producing a dummy); when the BODY has sites, after the condition push `i32.const 1` selected under rewind mode so the loop is entered; the `i32.eqz; br_if exit` stays. `Until` needs no replacement (its body runs before its condition). (4) `Times`: its prologue (`local.set n; i32.const 0; local.set i`) consumes the count: wrap it in `skip_in_rewind` (before = stack with the i32, after = without) so the restored `n` and `i` are kept; the exit test uses them. The per-iteration `local.get i` push before the body is a site-free straight-line segment: it is harmless in rewind (the body's first skipped run or the site drops it) but wrap it too if it is simpler to treat every segment uniformly. (5) `each`/`map`/`filter`/`fold`: wrap each straight-line segment a combinator emits before its body (the array pop into locals, `array_prologue`, `coll_loop_open`'s `local.set i`, the element load, `map`/`filter`'s destination setup, `fold`'s accumulator handling) in `skip_in_rewind` with the lowered checker stack before/after each segment; the loop-back code after the body runs only in normal mode and stays as it is. Instructions INSIDE the segment that are branches or block openers (`block`, `loop`, `br_if`) must not be inside a wrapper: split segments at them.
