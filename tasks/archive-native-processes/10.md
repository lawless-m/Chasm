Implement: (1) in lib.rs factor the body of `service_ring`'s loop into `pub fn service_entry(mem: &mut [u8], host: &mut dyn Host, op: i32, a0: i32, a1: i32, a2: i32) -> i32` (the four I/O opcodes; anything else `E_NOT_SUPPORTED`) and keep `service_ring` as the loop over it for untransformed modules, but remove its `Err(op)` refusal of process opcodes: `service_ring` now returns `()`, and process opcodes reaching it (a module without `wack.frames`, which the compiler no longer produces for process programs) complete with `E_NOT_SUPPORTED`; delete `PROCESSES_MESSAGE` and `ProcessesUnsupported` (the browser's `processes need JSPI` text is its own). (2) native.rs: `State` gains `sched: Option<Scheduler>`, `current: Pid`, `pending_user: HashMap<Pid, u32>`, and the module's memory; `Runner::instantiate` defines `wack.frames` as a mutable `anyref` global (null) besides `wack.spawn`, and creates two host-side anyref `Table`s (or one, 2 slots per pid) for each process's saved chain and closure; a module importing `wack.frames` takes the process path, any other module keeps today's synchronous path untouched. The process-path `ring_enter` (plain `func_wrap`, synchronous): read the one submission at SQ_HEAD and advance SQ_HEAD; OPEN of `/prog` or `/prog/...`, and READ/WRITE/CLOSE on a handle `>= PROG_HANDLE_BASE`, go to the scheduler's `prog_*`; other I/O opcodes to `service_entry` (I/O completes inline natively: a process is never in the io state); OP_SPAWN reads the `wack.spawn` global, clears it, stores the closure in the table at the new pid from `sched.spawn(a0)`, result 0; channel opcodes and OP_ALT to `sched.submit(current, ...)`: `Done(r)` writes the completion (user, r) at CQ_TAIL and advances it; `Park` stores the user in `pending_user`, stores `UNWINDING` at `UNWIND_MODE` and returns WITHOUT a completion. A process that killed itself through `/prog/<pid>/ctl` (its state is done after the write) also gets `UNWINDING` and no completion, so it unwinds. (3) The driver (`Runner::call`): run the export as process 0 (`sched.start_main()`, `current = 0`, call); after ANY entry returns: if the mode cell is `UNWINDING`: clear it, read `wack.frames` into the chain table at `current`, set the global null (a done/killed process's chain is dropped instead); else `sched.exit(current)` (for process 0 keep its returned values). Then loop: `sched.next()`: `start` → `current = pid`, call table slot `p.slot` (from the scheduler record) with `Val::AnyRef(closure)`; otherwise resume: put the chain back into the global, write the completion `(pending_user[pid], result)` at CQ_TAIL, store `REWINDING`, `current = pid`, call the same entry again with the same arguments; when nothing is ready: if process 0 has exited, the run is over (processes still parked are dropped: there are no later steps in `run`); else `sched.blocked(name)` must be `Some` (name: pid 0 = the export's word, `main` for `run`; others `process N`): kill 0 and end the run with `RunError { message: blocked, word: Some(name), process: None }`. A trap in any process ends the run with that trap: add `pub process: Option<u32>` to `RunError` (Display: ``trap in `w` (process N): msg`` when Some) and set it for pid > 0; `describe` is unchanged otherwise. Each driver iteration runs inside a `RootScope` so `Rooted` values from `Global::get` do not accumulate.
