This spike proves, before any compiler work, that the design's wasm shape is valid and runs on SYNCHRONOUS wasmtime 49 with WasmGC: a process that must wait never suspends; the host's `ring_enter` returns at once with a mode cell set to UNWIND (1); every function on the stack then saves its state (call-site index, all its locals, the operand values below the call) into a GC frame struct, pushes it on a linked chain held in an imported mutable `anyref` global `wack.frames` (callee's frame pushed first, so the head is the outermost frame), pushes dummy results and returns; the host keeps the chain, runs another process, and later resumes: restores the chain into the global, writes the completion, sets mode REWIND (2), calls the entry again; each function pops its frame, restores its locals, skips to the saved site (drop the whole dummy operand stack, push the saved operands, push dummy arguments, call again), down to the ring helper, which clears the mode and reads the completion.

Write a throwaway cargo project tmp/spike-unwind/ (Cargo.toml with an empty `[workspace]` table so the root workspace ignores it; deps `wasmtime = { version = "49", default-features = false, features = ["cranelift","runtime","std","gc","gc-copying"] }` and `wat = "1"` (wat 1.260 is in the local registry); NO async feature). Hand-write tmp/spike-unwind/spike.wat (the transform applied by hand) with: a memory with the mode cell at byte 0x11C and a completion cell; imports `wack.ring_enter` (no params), `wack.frames` (mutable anyref global), and `host.log (param i32)`; types: a rec group with a non-final base `$frame = struct (field (mut (ref null $frame)) next) (field (mut i32) site)` and, per call site, a FINAL subtype of `$frame` adding fields for every local of that function (including a struct-typed local `(ref null $point)` where `$point` is a GC struct with one i32 field) and for the operand values below the call; a helper `$ring (param i32) (result i32)` that: if mode==2 sets mode 0 and returns the completion cell; else calls `ring_enter` and, if mode==1 afterwards, returns 0 (dummy) without reading the completion, else returns the completion; two entry functions `a` and `b` each of the design's shape: entry prologue `if mode==2`: pop the head frame (`global.get wack.frames`, cast to `$frame`, tee into a local, `struct.get next` → `global.set`), `br_table` over the site index casting to the site's subtype and restoring every local (params included), remember the site in a local `resume`; a body that binds a `$point` struct (field = 1 for a, 2 for b) into a local, runs a 3-iteration counted loop (`block`/`loop` with the WHOLE current operand stack as block params, as the compiler emits) in which a `$point` reference and an i32 sit on the operand stack BELOW a call to `$ring` (site 0), followed by an `if` (also taking the whole stack as params) whose then-branch holds a second `$ring` call (site 1) and whose condition in rewind mode is replaced by `resume` falling in the then-branch's site range (use `select`); straight-line code before each site inside the loop and the if wrapped as `if mode==2 then drop the whole stack and push dummies (i32.const 0 / ref.null) else run it end`; after each call: `if mode==1`: drop the result, pop the operands below into scratch locals, `struct.new` the site's frame (next = `global.get wack.frames`), `global.set`, push dummy results, `return`; at each site in rewind mode when `resume` equals that site: drop everything, push the saved operands from the frame (`local.get frame`, `ref.cast` to the site subtype, `struct.get`), push dummy args, call; when `resume` differs: drop the inputs and push a dummy result without calling; at the end `host.log` the point's field and the loop counter. Harness src/main.rs: synchronous `Store`, engine as `wack_runtime::native::engine()` would configure (wasm_gc, function_references, Collector::Copying) but written locally (no path deps needed); `wack.frames` defined as a mutable anyref global; `ring_enter` as a plain `func_wrap` host function that sets the mode cell to 1 (every ring entry parks); keep each process's chain in a host-side anyref `Table` indexed by pid (read the global after the entry returns, store it in the table, set the global to null; on resume put it back) so chains stay rooted without `ManuallyRooted`; a driver that alternates a and b round-robin (start a, it parks; start b, it parks; resume a with completion 10, parks; resume b, ...) until both have returned, calling `store.gc()` (or allocating 200000 structs through a third exported churn function) between resumes; wrap each driver iteration in a `RootScope` so `Rooted` values from `Global::get` do not accumulate.
