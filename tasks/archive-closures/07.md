Design point (M10 closures, agreed): in the REPL a function value lives in the `wack.refs` anyref table like a struct (the line prologue/epilogue in crates/core/src/check.rs already branch on `ValType::Ref`, so the slot holds its refs index), and the stack echo, native and browser, shows ONLY the type: the value column of a `[ i32 -- i32 ]` entry is the type text itself (no `#slot`, no refs index). The same for a quotation-typed field inside a rendered struct.

Do:
