Design point (M10 closures, agreed, do not re-litigate): every function value is lowered as a WasmGC reference instead of today's i32 table index. `$closure = sub (struct (field i32))` holds the funcref-table slot; every function reachable through a value takes `(ref null $closure)` as its FIRST wasm parameter; `call` = `local.tee c; local.get c; struct.get $closure 0; call_indirect` with the env-extended signature `(ref null $closure, inputs...) -> outputs`. The funcref table and i32 slots stay, so REPL redefinition, `)force` and `)forget` keep working. `'word` gets a wrapper function per word (`[tick word]`: ignores param 0, pushes params 1.., calls the word directly or through the table per `Ctx::indirect_calls`) and pushes a capture-free `$closure` allocated per use (`i32.const slot; struct.new $closure`, no caching of the allocation). A quotation value word takes the env as param 0 too (its captures come in the next task; for now its env is a plain `$closure`). `eq` on function values = `ref.eq`; `hash` = `struct.get $closure 0` then the existing i32 mix. Programs and sessions that use no function values must compile byte-identically: the closure type is registered lazily on first use only.
