Read docs/reference.md section 14a and the channels section at the end of crates/core/src/prelude.wack first (`chan.send` etc. are prelude words that submit a ring opcode literal via `ring.submit ( a0 a1 a2 op -- result )`; the literal opcode directly before `ring.submit` marks the site as parking, and OP_SLEEP=12 is now in that set).

Decided (2026-10-06, replacing an earlier `( i32 -- chan i32 )` design that put its concrete `chan i32` and closure GC types into every module): `time.after` is generic, `( T i32 -- chan T )`: given a value and a count of milliseconds, a channel that receives that value once, that many milliseconds from now, and is then closed. Being generic, it is a prelude template made only on first use, like the channel words, so a program that never uses it gets no GC types from it. `time.sleep ( i32 -- )` uses only i32, makes no GC types, and stays a prelude word.

Append to crates/core/src/prelude.wack after `chan.taken`, in the file's existing style:

```
# ---------------------------------------------------------------- timers

: time.sleep ( i32 -- )  0 0 12 ring.submit drop ;  # OP_SLEEP

# A channel that receives v once, ms milliseconds from now, and is then
# closed: an `alt` arm on it is a timeout. Nobody receiving leaves its
# process parked on the send.
: time.after ( T i32 -- chan T )
  :> ms :> v
  chan.make ( chan T ) :> c
  [ ms time.sleep  c v chan.send  c chan.close ] spawn
  c ;
```
