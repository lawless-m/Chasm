Processes and channels": (1) the first paragraph says processes "switch only at channel operations and when a process finishes": make it "at channel operations, `time.sleep` and when a process finishes"; (2) add two rows to the word table: `time.sleep` `( i32 -- )` suspends the process for that many milliseconds (a negative count is 0); other processes run meanwhile; and `time.after` `( T i32 -- chan T )` given a value and a count, a channel that receives the value once, that many milliseconds from now, and is then closed; (3) after the `alt` paragraph add a short paragraph on timeouts: an `alt` arm on `time.after`'s channel is a timeout, and the value given to `time.after` is what that arm receives (so `-1 10 time.after` makes -1 the timeout's answer); `time.after` is a prelude word that spawns a process which sleeps, sends and closes, so when no one receives (the other arm won) that process stays parked on its send: a `run` or `test` drops it when process 0 returns, a REPL keeps it and `/prog` lists it; a sleeping process is never "blocked", so the all-processes-blocked trap fires only when nothing is ready and nothing sleeps; a run ends when `main` has returned even if other processes are still sleeping.
