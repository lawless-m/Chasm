TASK: create jpeg/bits.wack, the bit reader over entropy-coded data (T.81 F.2.2.5; libjpeg's jpeg_fill_bit_buffer in jdhuff.c is the behavioural reference; read it). Only this file is created; do not touch the M0 files.

Struct: `struct bitreader  data: bytes  pos: i32  buf: i32  nbits: i32  marker: i32  exhausted: i32`. data is the whole input; pos is the offset of the next unread byte; buf holds the bits read but not yet consumed, right-aligned, nbits of them (0 to 32, so an i32 is enough: a fill stops once more than 24 bits are held, as libjpeg's MIN_GET_BITS 25 on a 32-bit buffer); marker is 0 or the byte xx of an `FF xx` marker the reader has run into (the marker is left in the data for the scan layer); exhausted is the flag a later task sets when a request cannot be met (declare it now, leave it 0 here).

Words, contract first:
- `bits.open ( bytes i32 -- bitreader )`: data and the offset of the first entropy-coded byte (what scan.data-at holds); buf 0, nbits 0, marker 0, exhausted 0.
- `bits.fill ( bitreader -- )`: load bytes into buf while nbits <= 24, stopping early at a marker or at the end of the data. Exactly: loop while nbits <= 24: if marker is non-zero, leave; if pos >= data length, leave (end of data, marker stays 0); c = the byte at pos; if c != 0xFF: buf = (buf << 8) | c, nbits += 8, pos += 1; else (c is FF): let q = pos + 1 and advance q over any further FF bytes (q < len and byte q == FF); if q >= len, leave with pos unchanged (an FF, or a run of FFs, at the very end of the data is not a marker: the scan layer will find TRUNCATED there); if byte q == 0x00, it is a stuffed FF data byte: buf = (buf << 8) | 0xFF, nbits += 8, pos = q + 1 (several FFs followed by 00 count as one FF data byte, as libjpeg accepts); otherwise byte q is a marker: marker = byte q, pos stays at the FIRST FF of the run (so `FF xx`, with any fill FFs, is left for markers.next-marker, which skips fill FFs itself), leave. Every pass either leaves or advances pos, so the loop is bounded by the input length: say so in a comment. Use `bytes.at` only where the index has been compared with `bytes.len` first; bits.fill never traps and never refuses.
