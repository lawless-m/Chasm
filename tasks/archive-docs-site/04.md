Behaviour, in `main()` after the saved program has been replayed and `save(program)` called, before enabling the input: if `location.hash` starts with `#code=`, decode the rest as base64url (replace `-`→`+`, `_`→`/`, re-pad with `=`, `atob`, then decode the bytes as UTF-8 with TextDecoder) to get the example text. (Every checked example is a file, and a file holds only these top-level forms; a single chunk may hold a multi-line `union` or `struct` because the session parses a chunk starting with a keyword exactly as a file.) Finally `console.log("link ok")` when every step's `r.ok` was true, else `console.log("link FAIL " + <first error message or trap message or failed test word>)`.
