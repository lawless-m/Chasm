Fence convention (this is the project convention from now on; put it in a comment at the top of the script):
- info string exactly `chasm`: a complete program; it is checked, and the site gives it a Try-it button.
- info string `chasm fragment`: Chasm shown for its shape (relies on declarations not shown); highlighted on the site, never checked.
- info string `chasm-repl`: a REPL transcript (`> ` prompt lines and output); highlighted as a transcript, never checked.
- any other fence (plain, `json`, `sh`, ...): not Chasm, ignored.

Behaviour: the default file set is `docs/reference.md`, every `docs/tour/*.md` (sorted) and `site/index.md`; files or directories that do not exist yet are skipped silently. On a non-zero exit print `<file>:<line>: block failed` followed by the command's stdout and stderr, keep going, and exit 1 at the end. Count `chasm fragment` and `chasm-repl` blocks as skipped. The compiler binary is `$CHASM` if set, else `target/release/chasm`; if it does not exist, print one line saying to run `RUSTUP_TOOLCHAIN=1.99.0 cargo build --release -p chasm-cli` and exit 2.
