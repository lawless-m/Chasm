Repo: /home/matt/Git/Chasm. `site/build.py` renders fenced blocks through a single function `render_code(info, text, root)` as plain `<pre class="code" data-kind=...>`. Replace its body with highlighting and a Try-it link; no JavaScript on the pages.

1. `site/highlight.py`, stdlib only, exporting `highlight(text) -> str` (HTML with the text escaped) and `highlight_repl(text) -> str`. A small hand-written tokenizer over the Chasm lexical rules (docs/reference.md sections 2 to 4): `#` to end of line is a comment (`tok-c`); `"..."` with `\\` escapes is a string (`tok-s`); tokens are otherwise whitespace-separated; integers (optional `-`, decimal or `0x` hex) and floats (`1.5`, `2e10`) are numbers (`tok-n`); `:`, `;`, `export`, `declare`, `test`, `struct`, `union`, `->`, `:>` are keywords (`tok-k`); from `(` to the matching `)` is an effect or stack assertion (`tok-e`, including the `--`); `[` and `]` are quotation brackets (`tok-q`); a token ending in `:` (`circle:`, `else:`, `x:`) is a label (`tok-l`); `i32 i64 f32 f64 str array vec map option` and any token starting with an uppercase letter are types (`tok-t`); everything else is plain. `highlight_repl` treats lines starting with `> ` or `. ` as prompt + Chasm (prompt in `tok-c`, rest through `highlight`) and other lines as plain output.
2. In `render_code`: kind `chasm` → `<div class="code"><a class="try" href="{root}repl/#code={b64}">Try it</a><pre><code>` highlighted `</code></pre></div>` where `b64` is `base64.urlsafe_b64encode(text.encode()).rstrip(b"=")` of the block text exactly as written (trailing newline included); kind `fragment` → the same without the link; kind `repl` → `highlight_repl`; other fences → escaped plain `<pre><code>`. Keep `data-kind` on the wrapper.
3. `site/style.css`: colours for the eight token classes (readable in both schemes; comments dim, strings and numbers distinct, keywords bold-ish, effects subdued), `.code` as `position: relative` with `.try` as a small pill button in the top-right.
