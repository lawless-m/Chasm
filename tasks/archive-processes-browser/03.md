M11 adds CSP processes and channels; every host operation stays a ring entry (`crates/core/src/layout.rs` defines the ring and its opcodes 1 to 4), so modules that use no process word keep the single import `wack.ring_enter` and compile byte-identically. Add to `crates/core/src/layout.rs`, with doc comments stating the contract exactly as written here:
- `pub const OP_SPAWN: i32 = 5;` a0 = the funcref-table slot of the closure's code; the closure value itself is in the imported mutable `anyref` global `wack.spawn` (see `IMPORT_SPAWN`); result 0.
- `pub const OP_CHAN_MAKE: i32 = 6;` result: a new channel id (from 1, in creation order) with one sender.
- `pub const OP_CHAN_SENDER: i32 = 7;` a0 = id; one more sender; result 0.
- `pub const OP_CHAN_SEND: i32 = 8;` a0 = id; the sender has pushed its value onto the channel's queue in wasm; the process parks until a receiver takes that value; result 0, or `E_CLOSED` when the channel is closed.
- `pub const OP_CHAN_RECV: i32 = 9;` a0 = id; parks until a value is queued or the channel is closed and drained; result 1 = take the front value from the queue, 0 = closed and drained.
- `pub const OP_CHAN_CLOSE: i32 = 10;` a0 = id; one sender fewer; closed at zero; result 0, or `E_CLOSED` when it already had no senders.
- `pub const OP_ALT: i32 = 11;` a0 = address of `a1` little-endian i32 channel ids, a1 = their count; parks until one of them has a value or is closed and drained; result `2 * i + v` for arm `i`: `v` = 1 take a value from channel `i`, 0 that channel is closed and drained; the lowest ready arm wins.
- `pub const E_CLOSED: i32 = -7;` (a closed channel) after `E_MALFORMED`.
- `pub const IMPORT_SPAWN: &str = "spawn";` the mutable `anyref` global a module imports from `wack` only when it uses `spawn`.
Add all of them to `constants()` (negative codes cast to `u32` as the others are) and extend the `constants_for_hosts` test to cover `OP_ALT` and `E_CLOSED`. Verify: `cargo test -p wack-core` passes and `cargo build -p wack-core --target wasm32-unknown-unknown` succeeds. Done when both pass. Do not touch any other file.
