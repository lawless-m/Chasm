M11: `spawn ( [ -- ] -- )` is an ordinary word taking a function value and starting it as a process; the host starts it, so the closure must reach the host. Design: the module imports a mutable `anyref` global `(import "wack" "spawn" (global (mut anyref)))` (name `layout::IMPORT_SPAWN`) ONLY when `spawn` is used (new field `pub uses_spawn: bool` on `Ctx`, set in the emitting pass); a global import shifts no function index, and it is global 0 in both whole-program and step modules, which define no globals. `spawn` emits: `local.tee c` (a new local of type `(ref null $closure)`), `global.set 0`, `local.get c`, `struct.get $closure 0` (the slot), `i32.const 0`, `i32.const 0`, `i32.const OP_SPAWN` (= `layout::OP_SPAWN`, 5), `call rt.ring` (`FN_RING`), `drop`. The host reads the global during that ring entry, keeps the closure, clears the global, and later calls table slot `a0` with the closure as its argument (every `WordKind::Quote` function takes the closure as its last parameter). Spawning does not switch: the child is queued runnable and runs when the parent next parks or finishes.
