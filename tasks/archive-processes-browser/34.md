Decision: at `wack repl` a step is refused at run time, not at compile time (a step module does not carry reachability: a word defined with channel words in one step is run by a later line through the table), so the host trap from the previous task is the one REPL mechanism: a line or test that reaches `spawn`, a channel word or `alt` traps with `processes run only in the browser REPL for now`, the memory data stack is restored as for any trap, and the session stays usable. Read `crates/runtime/src/repl.rs` (`NativeRepl::new`: the linker's `ring_enter` closure; `call_slot`; `step`) and the previous task's changes in `crates/runtime/src/native.rs` and `lib.rs` (`service_ring -> Result<(), i32>`, `ProcessesUnsupported`, `PROCESSES_MESSAGE`).

Changes in `crates/runtime/src/repl.rs`: the `ring_enter` closure returns `Result<(), wasmtime::Error>` and maps a refused entry to `Err(wasmtime::Error::new(ProcessesUnsupported))` exactly as the Runner does; the linker defines `wack.spawn` as a mutable `anyref` global with a null value, so a step module that imports it (a line or definition using `spawn`) instantiates. Nothing else changes: `describe` already renders the message.

Tests: `crates/runtime/tests/repl.rs`: (1) `ok(&mut r, "7")` then `trap(&mut r, "chan.make ( chan i32 ) chan.recv")` has `trap.message == PROCESSES_MESSAGE` and the stack is still `[i32 7]`; (2) `trap(&mut r, "[ \"x\" println ] spawn")` traps with the same message and the step module instantiated (no diagnostics); (3) a definition `: produce ( chan i32 -- ) 1 chan.send ;` is accepted (`ok`), and the line `chan.make ( chan i32 ) produce` traps with the message; (4) `ok(&mut r, "1 2 i32.add")` afterwards gives `[i32 7, i32 3]` (the ring is consistent after a refusal); (5) `test` at the REPL: `test produce : chan.make ( chan i32 ) :> c c produce 1 -> 1` reports `TestStatus::Fail` with that error. `crates/cli/tests/repl.rs`: a piped session `printf 'chan.make ( chan i32 ) chan.recv\n' | wack repl` (through the `repl` helper) exits non-zero and prints a line containing `processes run only in the browser REPL for now` on stdout or stderr.
