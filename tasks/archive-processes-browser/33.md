Repo: /home/matt/Git/Whackford. Decision: the native hosts have no scheduler yet (the wasmtime spike in `tmp/spike-native.md` found no API to resume parked activations in non-LIFO order), so a ring submission with a process opcode (`op >= layout::OP_SPAWN`, i.e. OP_SPAWN=5 to OP_ALT=11, see `crates/core/src/layout.rs`) is refused at run time by a trap whose message is the stable text `processes run only in the browser REPL for now`. This is the backstop under the compile-time refusal in `wack run`/`wack test` and the only mechanism at `wack repl` (next task). Read `crates/runtime/src/lib.rs` (`service_ring`) and `crates/runtime/src/native.rs` (`Runner::instantiate`, `describe`).

Changes: (1) `crates/runtime/src/lib.rs`: `pub const PROCESSES_MESSAGE: &str = "processes run only in the browser REPL for now";` and `service_ring` now returns `Result<(), i32>`: it services entries as today; on an entry whose `op >= L::OP_SPAWN` it posts no completion, sets `SQ_HEAD` to `SQ_TAIL` (so the ring is consistent for later entries of a REPL session) and returns `Err(op)`. (2) `crates/runtime/src/native.rs`: `#[derive(Debug)] pub struct ProcessesUnsupported;` with `Display` printing `PROCESSES_MESSAGE` and `impl std::error::Error`; the `ring_enter` host function returns `Result<(), wasmtime::Error>` and maps `Err(_)` from `service_ring` to `Err(wasmtime::Error::new(ProcessesUnsupported))`; `instantiate` also defines in the linker a mutable `anyref` global `wack.spawn` (`layout::IMPORT_SPAWN`, null initial value) so a module that imports it (anything using `spawn`) instantiates and is refused at its first process operation rather than with wasmtime's unknown-import error; `describe` reports the message of a `ProcessesUnsupported` found by `e.downcast_ref::<ProcessesUnsupported>()` (checked after `trap_info` and before the `Trap` case), keeping the word from the backtrace as today.

Tests: new `crates/runtime/tests/procs.rs` compiling from source with `wack_core::compile` (`Options { prelude: true, test_exports: false, export: true, wasi: false }`, a `Config` with `Console::Capture` as in `crates/runtime/tests/repl.rs`): `Runner::new(&wasm).run_main(cfg)` for `: main ( -- ) [ "x" println ] spawn ;` gives `Err` with `message == PROCESSES_MESSAGE` and `word == Some("main")`; for `: main ( -- ) chan.make ( chan i32 ) chan.recv drop ;` gives `Err` with that message and a `word` starting with `chan.`; and `run_tests` on a `test_exports: true` compilation whose one test's word uses a channel reports `TestStatus::Fail` with that error.
