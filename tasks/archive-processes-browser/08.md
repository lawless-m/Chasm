M11's `alt` (`NodeKind::Alt(Vec<AltArm>)`, each arm `chan` node + body) waits for the first of several channels. Semantics: each arm's channel node must leave exactly one value of type `chan T_i` on top (anything else is `E_TYPE_MISMATCH` with `expected` `["chan T"]`; a `T_i` not yet known in the emitting pass is `E_AMBIGUOUS_TYPE`); the chosen arm receives `option T_i` (`some` with the value, `none` when that channel is closed and drained, as `chan.recv` does), arms are tried in the order written, every arm that does not diverge must leave the same stack (`E_BRANCH_MISMATCH`: "arms of `alt` disagree: arm 1 leaves ..., arm 2 leaves ..."). The host op is `layout::OP_ALT` (11): a0 = address of `count` little-endian i32 channel ids, a1 = count, result `2 * i + v` (arm index, v = 1 take a value).

Emission (in a new `fn alt_` beside `match_`): for each arm, walk its `chan` node from the current stack, pop the channel into a new local (in the emitting pass `self.ctx.register_type(&ty)` first and type the local `ref_ty(struct index)`; in the checking pass an `i32` placeholder as `match_` does). Then `i32.const 4*n`, `call FN_ALLOC` into a local `buf`; for each arm i: `local.get buf`, `local.get chan_i`, `struct.get <chan T_i struct index> 0` (field 0 is `id`), `i32.store` with offset `4*i`; then `local.get buf`, `i32.const n`, `i32.const 0`, `i32.const OP_ALT`, `call FN_RING` into local `r`. Dispatch as an if/else chain: arm i under `local.get r; i32.const 1; i32.shr_u; i32.const i; i32.eq; if <block type stack -> result>`; the arm's prefix is `local.get chan_i; local.get r; i32.const 1; i32.and; <call chan.taken<T_i>>` where the instance comes from `self.ctx.lookup("chan.taken")` plus `self.instance(...)` at `[T_i]`, called directly (`I::Call(Word::func_index(id))`) or through the table when `self.ctx.indirect_calls` (`I32Const(id)`, `CallIndirect` with `func_type(effect, false)`), recording a `Call` edge; push `option T_i` and inline the body with `seq_into` at the right `depth` as `match_` does; the final `else` is `unreachable`. Unify the arms' result stacks exactly as `match_`.
